# Sample Markdown Document

This is a test document for the Hermes markdown parser.

## Section 1: Introduction

Hermes is a local-first AI knowledge agent. It processes documents
and stores them in a vector database for retrieval.

## Section 2: Architecture

The system has four layers:

- **Transport Layer**: REST API, SSE, MCP
- **Core Layer**: Agent engine, LLM router, tool registry
- **Data Layer**: ChromaDB, document metadata, conversation memory
- **Pipeline Layer**: Document parsing, chunking, embedding

### Subsection 2.1: Parsers

The system supports multiple document formats:

1. PDF files
2. Text files
3. Markdown files
4. DOCX files
5. Code files

## Section 3: Conclusion

This document is used for testing the markdown parsing and chunking.
