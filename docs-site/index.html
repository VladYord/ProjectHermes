What you get

Private by default

Documents and vector embeddings stay on your machine. Offline mode works with local Ollama models.

Natural chat workflow

Streaming responses with conversation memory, source attribution, and a clean desktop UX.

Broad file support

PDF, DOCX, Markdown, text, code files, plus OCR for images with bundled Tesseract support.

Provider flexibility

Switch between Ollama, OpenAI, and Gemini without changing your document pipeline.

Semantic retrieval

ChromaDB-backed search keeps answers grounded in your local knowledge base.

MCP-ready

Connect Hermes tools from compatible clients like VS Code and Copilot workflows.
